# Paradise Nursery

Paradise Nursery is a responsive React shopping application for browsing
houseplants and managing a shopping cart.

## Features

- Landing page with a company introduction and Get Started button
- 18 unique houseplants across three categories
- Product thumbnails, names, prices, and Add to Cart buttons
- Redux Toolkit shopping cart
- Dynamic cart quantity in the navigation bar
- Cart item quantity controls, removal, and calculated totals
- Home, Plants, and Cart navigation
- Checkout placeholder

## Run locally

1. Install Node.js 20.19+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in the terminal.

## Deploy to GitHub Pages

1. Push this project to a public GitHub repository.
2. Run `npm run deploy`.
3. In the repository's **Settings → Pages**, select **Deploy from a branch**.
4. Choose the `gh-pages` branch and `/ (root)`, then save.

The application uses hash-based page navigation so its links work on
GitHub Pages.
